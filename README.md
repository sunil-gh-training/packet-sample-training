# Packet Sample (training repository)

Harmless training content used for GitHub workflow practice.

## Output label
The sample tool prints the output label **Packet Sample** for every processed packet.

## Files
- `src/sample-output.ts` – sample source that defines the output label
- `version.txt` – displayed version for this release
- `REQUIREMENTS.md` – requirements brief for this release
- `docs/operations.md` – operations guide
- `samples/sample-log.txt` – harmless sample log excerpt


## Usage
Run the sample with:

  npx ts-node src/sample-output.ts

It prints the configured output lable.
